## API Client

**Path:** `src/main/java/com/catastrophic/events/api`
**Responsibility:** Wraps OkHttp calls to the catabot backend's plugin API (`GET /events`, `POST /signup`, `POST /alerts`) behind an async callback interface, and classifies failures so callers can branch on cause (unauthorized vs. network vs. server).
**Entry point:** `EventsApiClient.java`

### Key files
| File | Purpose |
|------|---------|
| `EventsApiClient.java` | `fetchEvents()` and `signup()` - builds requests, attaches Bearer auth header, parses JSON via Gson, routes errors through `ApiCallback`. |
| `AlertsApiClient.java` | `sendAlert()` - posts multipart/form-data (`kind`, `summary`, `image`) to `POST /alerts` with the same Bearer auth pattern; has its own inline 401/unsuccessful/network handling rather than sharing `EventsApiClient`'s (WRN-005). |
| `ApiCallback.java` | Generic async result interface (`onSuccess`/`onError`) used by all API calls. |
| `ApiErrorType.java` | Enum classifying failures: `UNAUTHORIZED` (401), `NETWORK` (never reached server), `SERVER` (unexpected status/malformed body). |

### Dependencies
- **Depends on:** `src/main/java/com/catastrophic/events/api/dto`
- **Used by:** `src/main/java/com/catastrophic/events`, `src/main/java/com/catastrophic/events/alerts`

## Alerts

**Path:** `src/main/java/com/catastrophic/events/alerts`
**Responsibility:** Game-event listeners (`@Subscribe` on RuneLite's `EventBus`) that detect loot/death/clan-coffer moments client-side, capture a screenshot, and send it (plus a text summary) to `AlertsApiClient` for delivery to Discord via catabot.
**Entry points:** `LootAlertListener.java`, `DeathAlertListener.java`, `CofferAlertListener.java`

### Key files
| File | Purpose |
|------|---------|
| `AlertKind.java` | `LOOT`/`DEATH`/`COFFER` enum; `wireValue()` matches the bot's `kind` field. |
| `ScreenshotCapture.java` | Wraps `DrawManager.requestNextFrameListener` to capture the current client frame as PNG bytes via an async callback. |
| `LootAlertListener.java` | `@Subscribe` on `NpcLootReceived`/`PlayerLootReceived`; filters to non-stackable items worth >= 1.5m gp (`ItemManager.getItemPrice`); gated on `config.lootSharingEnabled()` (default off). |
| `DeathAlertListener.java` | `@Subscribe` on `ActorDeath`, local player only; gated on `config.deathScreenshotsEnabled()` (default off); uses `config.deathMessage()` if set, else "Died." |
| `CofferAlertListener.java` | `@Subscribe` on `ChatMessage` (`ChatMessageType.CLAN_MESSAGE` only - the system-broadcast type, not player-typed `CLAN_CHAT`); regex-matches coffer deposit/withdraw text; always on, no config gate. |

### Dependencies
- **Depends on:** `src/main/java/com/catastrophic/events`, `src/main/java/com/catastrophic/events/api`
- **Used by:** `src/main/java/com/catastrophic/events`

### Concerns
None currently tracked.
