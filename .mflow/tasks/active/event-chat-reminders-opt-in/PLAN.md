## Steps

### Step 1 — Config toggle
`CatastrophicEventsConfig.java`: add `@ConfigItem(position = 5, keyName = "eventRemindersEnabled", name = "Event chat reminders", ...)`, default `false`, with a description covering both the T-3h/T-1h/T-5min milestone reminders and the once-per-session signed-up-events summary.
