# Catastrophic Events

## Overview
A RuneLite side-panel plugin for the Catastrophic Events clan's tooling. Lets members browse upcoming clan events, sign up with one click, and get private in-client reminders before they start. Talks over HTTP to the `catabot` Discord bot's plugin-facing API (a sibling repo) rather than to any backend hosted in this repository.

## Stack
- **Language:** Java 11
- **Framework:** RuneLite Client Plugin API (Guice DI)
- **Database:** none (client-side plugin; backend data lives behind `catabot`'s API)
- **ORM:** none
- **Frontend:** Java Swing, custom-painted (via RuneLite `PluginPanel`, no default L&F chrome)
- **Hosting:** RuneLite Plugin Hub (distribution only — the plugin runs inside each user's own RuneLite client)

## Architecture
Layered plugin architecture following RuneLite's standard external-plugin shape: `CatastrophicEventsPlugin` is the Guice-injected orchestrator (lifecycle, poll loop, reminder logic); `api/` holds the OkHttp-based `EventsApiClient` plus an async `ApiCallback<T>`/`ApiErrorType` pattern; `api/dto/` mirrors the bot's JSON contract via Gson; `ui/` holds a state-routed `CatastrophicEventsPanel` (NOT_LINKED / CONNECTION_ERROR / EVENTS states, All Events / My Events tabs) built from presentational cards (`EventHeroCard`, `EventCompactRow`) and a small custom Swing widget kit (`StyledButton`, `RoundedPanel`, `CatastrophicTheme`, etc.). See [`architecture.json`](architecture.json) for full layer and decision detail.

## Key conventions
Allman brace style with tab indentation throughout `src/` (a deliberate deviation from common Java style). Lombok used for boilerplate (`@Slf4j`, `@Getter`, `@RequiredArgsConstructor`). DTOs are grouped by layer, not by feature, and use Gson `@SerializedName` to bridge the backend's snake_case JSON to camelCase Java fields. No `var` usage; no nullability annotations — null-safety is handled with manual checks and try/catch. No CI/CD pipeline exists yet. See [`conventions.json`](conventions.json) for full detail.
